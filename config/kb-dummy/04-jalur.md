# Jalur pendaftaran
DUMMY. Jalur pendaftaran yang tersedia adalah jalur prestasi, jalur tes tulis, dan jalur mandiri.

# Program studi
DUMMY. Program studi sarjana yang dibuka antara lain Pendidikan Matematika (S1-PMAT), Teknik Informatika (S1-TI), dan Manajemen (S1-MNJ).

# Program studi Teknik Informatika {program=S1-TI}
DUMMY. Program studi Teknik Informatika jalur mandiri mensyaratkan nilai rata-rata rapor matematika minimal 75.
