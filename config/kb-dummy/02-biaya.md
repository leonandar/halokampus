# Biaya pendaftaran
DUMMY. Biaya pendaftaran jalur mandiri sebesar Rp250.000 untuk program sarjana dan Rp350.000 untuk program pascasarjana. Biaya dibayarkan melalui virtual account yang muncul di portal setelah formulir diisi.

# Kebijakan biaya
DUMMY. Biaya pendaftaran yang sudah dibayarkan tidak dapat dikembalikan. Kendala pembayaran ditangani langsung oleh Staf PMB.
